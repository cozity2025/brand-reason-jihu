데이터 백업

사이트의 주요 데이터를 파일로 내려받아 보관하세요.
비밀번호·API 키·결제 비밀값 같은 민감정보는 백업 파일에 들어가지 않아요.

전체 백업 (JSON)

사이트 설정, 상품, 커리큘럼, 페이지, 관리자 계정 정보를 한 파일로 내려받아요.

백업에 포함

  • 사이트 설정 (이름, 주소, SEO, 분석·모니터링 설정)
  • 상품 (이름, 가격, 구성)
  • 멤버십 요금제 (월 구독)
  • 커리큘럼·페이지 구성
  • 관리자 계정 (이름, 권한)

백업에서 제외

  • 비밀번호·비밀번호 해시
  • API 키·토큰
  • 결제 비밀키
  • 카드·계좌번호 등 금융정보

제외 기준: 필드 이름에 password, secret, token, apiKey, card 등이 들어가면 서버에서 값을 빼고 내보내요. 빠진 항목의 이름만 백업 파일의 meta.excludedFields에 기록돼요.
